# 软件架构

程序实现在com.kenny.localmanager中，主Activity按一般习惯，是默认的MainActivity。
绘制先按管理先绘制LocalManagerTheme，用来设定配色等基本设置，然后在这个Theme上
绘制真正的界面，`FileBrowserApp()`。

## 主界面

`FileBrowserApp()` 是融合界面，定义一组

拣选模式 Tab 切换、独立 `pickList`）。

### 单个文件解释

#### MainActivity

* companion object 定义类伴生数据（相当于类的static成员），这里定义了一个常数
  LAUNCH_TARGET_EXTRA，用于或者应用启动参数（就是通过打开什么应用打开）

* 主类定义了两个可变状态记录前面的启动参数数据，定义成MutableState，表示这个数
  据带着触发函数，被修改的时候自动触发Compose刷新界面。（注意它不是封装，而是直
  接可以赋值进去的变量，用起来是这样的：var x: MutableState<String>? = y; x = z;）

* 两个可变状态记录有两个更新时机，一个是onCreate()的时候，一个是onNewIntent()的时候，
  后者是在后台的时候又从其他线程上调度，这时界面的绘制资源都在，只需要更新一下
  MutableState刷新界面就行。

* 崩溃跟踪直接定义成object，所以可以带着数据调用，处理死机记录：
  CrashReportStore.install(this)。不需要数据的就直接调用其他文件的函数：
  syncPinnedTabShortcuts(this)

* 主界面先用界面风格LocalManagerTheme包住FileBrowserApp，以便可以整体调整风格。
