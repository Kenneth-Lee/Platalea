# 目录位置记忆参数

本文说明目录浏览位置记忆功能的当前策略与参数，便于用户理解行为和排查问题。

## 功能目标

- 离开目录后记住当前浏览位置。
- 下次进入同一目录时，尽量恢复到离开前位置。
- 避免记录无限增长。

## 当前参数

- 记忆启用阈值：目录项目数 >= 30。
- 最大记录条目数：400。
- 过期时间策略：不启用（不按时间删除）。

说明：当记录数超过 400 时，会按最近访问优先保留，超出的旧记录会被淘汰。

## 恢复策略

进入目录时，按以下顺序尝试恢复位置：

1. 锚点 URI：优先按离开时可见锚点项的 URI 定位。
2. 锚点文件名：URI 不可用时，按文件名尝试定位。
3. 指纹+索引兜底：目录头部指纹一致时，按索引恢复。
4. 以上都失败：回到顶部，避免跳到错误位置。

## 保存时机

为减少“退出应用后丢记录”的概率，保存会在以下时机触发：

- 目录页进入后台（ON_STOP）。
- 目录页销毁（onDispose）。

## 为什么有阈值

小目录通常无需位置记忆，阈值可以减少无意义记录和写入次数。当前阈值为 30，可根据实际体验调整。
